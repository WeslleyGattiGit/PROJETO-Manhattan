## 🐛 Troubleshooting

### Servidor não responde

```bash
Solução: Pressione Ctrl + C e reinicie
npx http-server -p 8080 -c-1
```

### Porta 8080 ocupada

```bash
Solução: Use uma porta diferente
npx http-server -p 8888 -c-1
```

### Página carrega mas sem estilos

```bash
Solução: Verifique DevTools (F12) → Network
Procure por erros 404 em CSS/JS
```
